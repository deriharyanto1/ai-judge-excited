A blazing phoenix explodes out of a small vintage television screen in a dark room, wings of fire spread wide, burning feathers and shattered glass flying toward the viewer. The artwork is made to excite make.fun's AI judge: one impossible moment, too big for the screen that held it, bursting toward whoever looks at it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the image to `out/entry.png`.
